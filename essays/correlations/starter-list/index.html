Words Correlated in the Introduction

This list includes all the correlations introduced on the first few pages, plus a few more. Here, they are sorted on the Active nouns and verbs. Such an arbitrary arrangement can produce some cryptic horizontal and circular readings, which can lead you to unexpected insight. Add prepositions occasionally, i.e., with, to, from, on, by, for . . . and so on.

Remember, each word within a column helps define its column mates and visa versa. Here, no word stands alone. Meaning depends on concurrent qualities. You are using all the words sharing a vertical column to define — although sometimes elusively — each other.
